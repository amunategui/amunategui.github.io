Open both in the same browser (two windows side by side is the idea) and leave Link · on in each console. Deep Field then hands Sub Division its tempo and key; drag the tempo dial in either app and the other follows. Sub Division's Feel ×2 turns Deep Field's 56 bpm into a 112 bpm groove — switch to ×1 for a true one-to-one lock. If Link is off, just set the same BPM by hand.
